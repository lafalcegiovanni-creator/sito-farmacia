# Sito Farmacia La Falce Giovanni

Sito e blog "Per la tua salute è utile sapere…" della Farmacia La Falce Giovanni, Via Fasano 112, Gravina di Catania.

- `sito/` – il sito completo da pubblicare su Aruba
- `blog/` – articoli e programma che crea le pagine del blog
- `verifica/` – il sito in un unico file, solo per anteprima (da non pubblicare)

Istruzioni dettagliate in `CLAUDE.md`.
